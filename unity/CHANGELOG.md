# Changelog

## 1.0.0 (unreleased)

The first release: the Clomni Messenger in Unity on Android and iOS through the native SDKs, with the same calls as
the React Native and Flutter packages (opening it, users, flows, push, theme, sounds, language, log level) and their
events as C# events (`UnreadCountChanged`, `MessengerOpened`, `MessengerClosed`, `ConversationStarted`,
`FlowCompleted`, `OnLink`). Native dependencies through EDM4U; samples for the basic calls and for Firebase push.
